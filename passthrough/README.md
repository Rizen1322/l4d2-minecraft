# L4D2 + настоящий Minecraft: локальный прототип

Minecraft Java 26.3/Fabric 0.19.5 работает отдельным процессом. L4D2 остаётся
движком движения, карты и заражённых; предметы и рука приходят из Minecraft. FrameExporter из MIT-примера
universal-modder передаёт цвет, глубину и отдельный HUD/руку. Собственный x86
ReShade add-on совмещает кадры и компенсирует задержку камеры.

## Запуск

1. В Legacy Launcher запустить **L4D2MC-Fabric-26.3** обычным способом.
2. Не сворачивать Minecraft: окно можно оставить за окном L4D2.
3. Запустить `../Play-Minecraft.cmd`. Он запускает локальную c1m1_hotel с
   `-insecure`, включает тестовый VScript-мост и временно отключает VPK-аддоны.
   После выхода из L4D2 восстанавливает исходный addonlist.
4. **ЛКМ** — атака/разрушение; **ПКМ** — предмет/строительство, дверь или
   кнопка L4D2; **E/F9** — настоящий инвентарь; **1–9/колесо** — хотбар;
   **Q** — выбросить, **Ctrl+Q** — весь стек; **F** — другая рука;
   **T/** — чат/команда; **F5** — камера со Стивом.
   WASD, прыжок, скорость и приседание сохраняют ваши бинды L4D2.
   Source-оружие собственного игрока скрыто, ЛКМ/ПКМ заняты Minecraft.
   В инвентаре работают отдельные SDL-клики, перетаскивание и клавиатура.
   Новому JAR нужен полный перезапуск Minecraft.


Гостевой каталог: `passthrough/guest-game`, мир `saves/l4d2mc-guest`. Профиль
использует официальный клиент и Fabric и оставляет авторизацию обычному
лаунчеру. Токены и аккаунты не копируются. OptiFine-профиль не заменяется.
Логи самого клиента лаунчер пока пишет в обычный `game/logs/latest.log`,
несмотря на отдельные миры и настройки гостя.

## Проверено на этой машине

- Guest JAR собирается JDK 25.0.1; x86 PE add-on имеет AddonInit и загружается
  ReShade 6.8.0 / API 20 в L4D2 Build 10097.
- Шейдер компилируется в Direct3D 9. Настоящие Minecraft HUD/рука и блоки
  видны поверх реальной карты Dead Center. Фото в `evidence/` — игровые кадры.
- Обратное сообщение о настоящем блоке создаёт невидимый Source prop.
  Игровая трасса попала в ожидаемую грань: `[L4D2MC COLLISION TEST] PASS`,
  face=639.969, ожидаемая грань около 640.
- 35 Python-теста проверяют оси/направления камеры, FOV, границы снимка
  коллизий, смену карты и отклонение некорректных данных.
- Выбор предметов мышью и перенос в хотбар проверены в окне L4D2. При
  cl_mouseenable=0 углы камеры Source не изменились во время двух кликов.
  Скриншот блока не доказывает корректность всей глубины.

## Ограничения прототипа

- Передача камеры через VScript/файл около 30 Гц вызывает задержки и иногда
  предупреждения Script Perf. Нужен нативный адаптер текущей render-камеры.
- Калибровка near/far 7/30000 предварительная. MSAA мешало отображению мира;
  после сброса видеорежима без multisampling блоки появились. Корректное
  скрытие за стеной и стабильность при быстрых движениях ещё проверяются.
- Только ближайшие 512 твёрдых блоков становятся полноразмерными Source
  кубами. Ступени/плиты/двери Minecraft пока имеют грубую кубическую коллизию.
  Navmesh заражённых не обновляется. Спавн внутри живого игрока пропускается.
- Пол и стены для установки обычных блоков определяет луч в карте Source.
  Невидимые барьеры больше не создаются; старые удаляются один раз на чанк
  только в собственном overworld l4d2mc-guest. Предметам вроде факелов ещё
  нужна Minecraft-опора: виртуальная поверхность для их canSurvive не реализована.
- Разные карты ещё не разделяют постройки по отдельным гостевым областям.
  Тестировать пока c1m1_hotel, не проходить кампанию с этим гостевым миром.
- F5 использует настоящий Minecraft-аватар Steve и скрывает собственную
  модель Source. Сложные анимации L4D2 (лестницы, захват, смерть) ещё не согласованы.
- Установлены временные плоскости Source для Minecraft TNT/мобов/предметов.
  Они не становятся сохранёнными или выбираемыми блоками. Поиск пути мобов
  вокруг сложных стен Source и ответная стрельба Source-ботов по мобам не готовы.
- Новая сборка запущена в обеих играх. Проверены инвентарь, TNT, лечение
  и атаки големов. Это действующий прототип, не законченная total conversion.

## Сборка и удаление

`build.ps1` использует существующий JDK из лаунчера и официальный portable Zig
0.15.2, проверенный SHA-256 из ziglang.org/download/index.json. SDK ReShade
получен с официального GitHub tag v6.8.0. Для MSVC x86 ABI возвращаемый handle
в `find_uniform_variable` вызывается через явный result pointer: простой
MinGW-вызов вызывал подтверждённый дампом вылет.

`python passthrough/install.py uninstall` удаляет только собственные неизменённые
файлы по SHA-256 receipt `backups/passthrough-install.json`. Миры сохраняются.
Изменённые игрой/пользователем ReShade-конфиги остаются и перечисляются.
При аварийном закрытии launcher исходный addonlist есть в
`backups/passthrough-launch-addonlist.txt`.

Основной MIT-код: universal-modder, copyright Rehan and contributors.
Лицензии в `guest/LICENSE` и `native/LICENSE`. ReShade и Minecraft-бинарники
не входят в исходники проекта и не предназначены для перепубликации.


Мост сбрасывает снимок коллизий при переподключении и заново запрашивает
блоки после первой синхронизации камеры. Коллизии выключаются, если гостевые
кадры устарели; Source удаляет их через 3 секунды отсутствия новых снимков.
При разрыве управляющего подключения гостевой мод отпускает переданные клавиши Minecraft.
Launcher следит за процессом моста и возвращает управление мышью при его
ошибке. Recovery-marker не даёт затереть резервную копию Workshop-флагов после
аварийного завершения launcher. Конфиг запуска получает уникальное имя.

Исправления камеры и строительства (2026-10-08): кадр Minecraft и его поза
копируются одним согласованным снимком; перепроекция отклоняет ложные
попадания на границах глубины. Для проверенной c1m1_hotel в Generic Depth
закреплён CLEAR 2 (DepthCopyAtClearIndex=2): такой выбор прошёл локальные проверки скрытия построек за стеной.
На других картах последовательность проходов требует отдельной проверки.
Резервная копия гостевого мира: backups/guest-before-support-migration-20261008.

Камера дополнительно сверяется с независимой позицией игрока из VScript:
пойманный скачок служебной камеры на 341 блок отклоняется, сохраняются
последние корректные FOV и clip planes. Динамические GPU-текстуры меняются
согласованным комплектом цвет/глубина/HUD. Перепроекция при движении сначала
отслеживает видимую поверхность и проверяет более близкие попадания; это
устранило обрезание блоков при ходьбе по проверке пользователя. Доставка
камеры опрашивается примерно каждые 4 мс вместо 15 мс. При резких движениях
остаётся задержка отдельных процессов и открытие поверхностей, которых ещё
нет в предыдущем гостевом кадре: полное отсутствие таких артефактов не доказано.
Новые кубы на поверхности между линиями сетки выбираются целиком снаружи;
зазор до исходной поверхности может быть меньше одного куба.

Проверки исправлений 2026-10-08: Source сохраняет множитель движения 1;
повтор одного события создаёт один взрыв, сущность удаляется через 0.2 секунды;
тестовый заражённый поражён. ЛКМ GUI использует SDL_BUTTON_LEFT=1,
ПКМ — SDL_BUTTON_RIGHT=3 (в 26.3 уже не GLFW 0/1). Курсор Source освобождается
через VGUI_Surface031; проверено удержание вне центра 2.4 секунды.
Тестовая дверь прошла закрыто→открывается через новое событие interact.
Трасса TNT нашла настоящий пол даже внутри старого временного куба.

Сверка блока с миром теперь атомарно заменяет область, включая отсутствующие
блоки, каждые 2 секунды; ближайшие 512 коллизий ограничены общим бюджетом 1400
сущностей Source. Големы выбирают заражённых, goal-driven враждебные мобы —
выживших. Урон Minecraft по Source при ударе умножается на 15 с учётом
ванильного восстановления удара. Неподтверждённые вызовы команд через native
vtable убраны после вылета на E. Повтор E не должен открывать только что
закрытый экран; Source получает VGUI dc_none=1 при возврате камеры. В новом госте проверены три закрытия экрана через E, големы наносят
урон заражённым Source; еда вызвала реальные события лечения. Тестовый
TNT сохранил положение на полу в двух последовательных измерениях.

Изменения следующей сборки (подготовлены без запуска игр по просьбе пользователя):
- Жемчуг учитывает попадания в карту Source; хорус ищет место на её полу.
  Место телепорта проверяется лучами по габаритам персонажа; TraceHull
  в этой версии VScript отсутствует.
- ПКМ поддерживает удержание Source Use. ЛКМ передаёт Source Attack
  только для переносимых предметов событий (канистра, кола и подобные).
- Голем и обычные враждебные мобы преследуют Source-цели через реальные
  коллизии; скелеты сохраняют стрельбу, криперы — подготовку взрыва.
  Полноценный маршрут по navmesh Source и brain-driven мобы пока не реализованы.
- При загрузке и внешней камере/заморозке сцены композиция и ввод Minecraft
  отключаются. Курсор скрывается и его состояние восстанавливается по фокусу.
- Launcher принимает `-Map c2m1_highway` и другие имена карт Source.
  Добавлен захват наиболее крупного прохода глубины основной камеры,
  независимо от номера очистки. При неподдерживаемых поверхностях/MSAA
  сохраняется Generic Depth. Последняя проверенная настройка CLEAR2 относится
  к c1m1_hotel; новая глубина и другие карты ещё не проверены в игре.

Последняя сборка Java/native и35 Python-теста проходят. Новые телепорты,
удержания, преследование, скрытие курсора и глубина требуют игровой проверки.

Команды восстановления/подключения теперь ждут окончания загрузки Source,
чтобы не отправлять hijack-запрос в момент, когда движок его отклоняет.
