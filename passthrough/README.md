# L4D2 + настоящий Minecraft: локальный прототип

Minecraft Java 26.3/Fabric 0.19.5 работает отдельным процессом. L4D2 остаётся
движком движения, карты и заражённых; предметы и рука приходят из Minecraft. FrameExporter из MIT-примера
universal-modder передаёт цвет, глубину и отдельный HUD/руку. Собственный x86
ReShade add-on совмещает кадры и компенсирует задержку камеры.

## Запуск

1. В Legacy Launcher запустить **L4D2MC-Fabric-26.3** обычным способом.
2. Не сворачивать Minecraft: окно можно оставить за окном L4D2.
3. Запустить `../Play-Minecraft.cmd`. Он запускает локальную c1m1_hotel с
   `-insecure`, включает тестовый VScript-мост и временно отключает VPK-аддоны.
   После выхода из L4D2 восстанавливает исходный addonlist.
4. **ЛКМ** — атака/разрушение; **ПКМ** — предмет/строительство, дверь или
   кнопка L4D2; **E/F9** — настоящий инвентарь; **1–9/колесо** — хотбар;
   **Q** — выбросить, **Ctrl+Q** — весь стек; **F** — другая рука;
   **T/** — чат/команда; **F5** — камера со Стивом.
   WASD, прыжок, скорость и приседание сохраняют ваши бинды L4D2.
   Source-оружие собственного игрока скрыто, ЛКМ/ПКМ заняты Minecraft.
   В инвентаре работают отдельные SDL-клики, перетаскивание и клавиатура.
   Новому JAR нужен полный перезапуск Minecraft.


Гостевой каталог: `passthrough/guest-game`, мир `saves/l4d2mc-guest`. Профиль
использует официальный клиент и Fabric и оставляет авторизацию обычному
лаунчеру. Токены и аккаунты не копируются. OptiFine-профиль не заменяется.
Логи самого клиента лаунчер пока пишет в обычный `game/logs/latest.log`,
несмотря на отдельные миры и настройки гостя.

## Проверено на этой машине

- Guest JAR собирается JDK 25.0.1; x86 PE add-on имеет AddonInit и загружается
  ReShade 6.8.0 / API 20 в L4D2 Build 10097.
- Шейдер компилируется в Direct3D 9. Настоящие Minecraft HUD/рука и блоки
  видны поверх реальной карты Dead Center. Фото в `evidence/` — игровые кадры.
- Обратное сообщение о настоящем блоке создаёт невидимый Source prop.
  Игровая трасса попала в ожидаемую грань: `[L4D2MC COLLISION TEST] PASS`,
  face=639.969, ожидаемая грань около 640.
- 35 Python-теста проверяют оси/направления камеры, FOV, границы снимка
  коллизий, смену карты и отклонение некорректных данных.
- Выбор предметов мышью и перенос в хотбар проверены в окне L4D2. При
  cl_mouseenable=0 углы камеры Source не изменились во время двух кликов.
  Скриншот блока не доказывает корректность всей глубины.

## Ограничения прототипа

- Передача камеры через VScript/файл около 30 Гц вызывает задержки и иногда
  предупреждения Script Perf. Нужен нативный адаптер текущей render-камеры.
- Калибровка near/far 7/30000 предварительная. MSAA мешало отображению мира;
  после сброса видеорежима без multisampling блоки появились. Корректное
  скрытие за стеной и стабильность при быстрых движениях ещё проверяются.
- Только ближайшие 512 твёрдых блоков становятся полноразмерными Source
  кубами. Ступени/плиты/двери Minecraft пока имеют грубую кубическую коллизию.
  Navmesh заражённых не обновляется. Спавн внутри живого игрока пропускается.
- Пол и стены для установки обычных блоков определяет луч в карте Source.
  Невидимые барьеры больше не создаются; старые удаляются один раз на чанк
  только в собственном overworld l4d2mc-guest. Предметам вроде факелов ещё
  нужна Minecraft-опора: виртуальная поверхность для их canSurvive не реализована.
- Разные карты ещё не разделяют постройки по отдельным гостевым областям.
  Тестировать пока c1m1_hotel, не проходить кампанию с этим гостевым миром.
- F5 использует настоящий Minecraft-аватар Steve и скрывает собственную
  модель Source. Сложные анимации L4D2 (лестницы, захват, смерть) ещё не согласованы.
- Установлены временные плоскости Source для Minecraft TNT/мобов/предметов.
  Они не становятся сохранёнными или выбираемыми блоками. Поиск пути мобов
  вокруг сложных стен Source и ответная стрельба Source-ботов по мобам не готовы.
- Новая сборка запущена в обеих играх. Проверены инвентарь, TNT, лечение
  и атаки големов. Это действующий прототип, не законченная total conversion.

## Сборка и удаление

`build.ps1` использует существующий JDK из лаунчера и официальный portable Zig
0.15.2, проверенный SHA-256 из ziglang.org/download/index.json. SDK ReShade
получен с официального GitHub tag v6.8.0. Для MSVC x86 ABI возвращаемый handle
в `find_uniform_variable` вызывается через явный result pointer: простой
MinGW-вызов вызывал подтверждённый дампом вылет.

`python passthrough/install.py uninstall` удаляет только собственные неизменённые
файлы по SHA-256 receipt `backups/passthrough-install.json`. Миры сохраняются.
Изменённые игрой/пользователем ReShade-конфиги остаются и перечисляются.
При аварийном закрытии launcher исходный addonlist есть в
`backups/passthrough-launch-addonlist.txt`.

Основной MIT-код: universal-modder, copyright Rehan and contributors.
Лицензии в `guest/LICENSE` и `native/LICENSE`. ReShade и Minecraft-бинарники
не входят в исходники проекта и не предназначены для перепубликации.


Мост сбрасывает снимок коллизий при переподключении и заново запрашивает
блоки после первой синхронизации камеры. Коллизии выключаются, если гостевые
кадры устарели; Source удаляет их через 3 секунды отсутствия новых снимков.
При разрыве управляющего подключения гостевой мод отпускает переданные клавиши Minecraft.
Launcher следит за процессом моста и возвращает управление мышью при его
ошибке. Recovery-marker не даёт затереть резервную копию Workshop-флагов после
аварийного завершения launcher. Конфиг запуска получает уникальное имя.

Исправления камеры и строительства (2026-10-08): кадр Minecraft и его поза
копируются одним согласованным снимком; перепроекция отклоняет ложные
попадания на границах глубины. Для проверенной c1m1_hotel в Generic Depth
закреплён CLEAR 2 (DepthCopyAtClearIndex=2): такой выбор прошёл локальные проверки скрытия построек за стеной.
На других картах последовательность проходов требует отдельной проверки.
Резервная копия гостевого мира: backups/guest-before-support-migration-20261008.

Камера дополнительно сверяется с независимой позицией игрока из VScript:
пойманный скачок служебной камеры на 341 блок отклоняется, сохраняются
последние корректные FOV и clip planes. Динамические GPU-текстуры меняются
согласованным комплектом цвет/глубина/HUD. Перепроекция при движении сначала
отслеживает видимую поверхность и проверяет более близкие попадания; это
устранило обрезание блоков при ходьбе по проверке пользователя. Доставка
камеры опрашивается примерно каждые 4 мс вместо 15 мс. При резких движениях
остаётся задержка отдельных процессов и открытие поверхностей, которых ещё
нет в предыдущем гостевом кадре: полное отсутствие таких артефактов не доказано.
Новые кубы на поверхности между линиями сетки выбираются целиком снаружи;
зазор до исходной поверхности может быть меньше одного куба.

Проверки исправлений 2026-10-08: Source сохраняет множитель движения 1;
повтор одного события создаёт один взрыв, сущность удаляется через 0.2 секунды;
тестовый заражённый поражён. ЛКМ GUI использует SDL_BUTTON_LEFT=1,
ПКМ — SDL_BUTTON_RIGHT=3 (в 26.3 уже не GLFW 0/1). Курсор Source освобождается
через VGUI_Surface031; проверено удержание вне центра 2.4 секунды.
Тестовая дверь прошла закрыто→открывается через новое событие interact.
Трасса TNT нашла настоящий пол даже внутри старого временного куба.

Сверка блока с миром теперь атомарно заменяет область, включая отсутствующие
блоки, каждые 2 секунды; ближайшие 512 коллизий ограничены общим бюджетом 1400
сущностей Source. Големы выбирают заражённых, goal-driven враждебные мобы —
выживших. Урон Minecraft по Source при ударе умножается на 15 с учётом
ванильного восстановления удара. Неподтверждённые вызовы команд через native
vtable убраны после вылета на E. Повтор E не должен открывать только что
закрытый экран; Source получает VGUI dc_none=1 при возврате камеры. В новом госте проверены три закрытия экрана через E, големы наносят
урон заражённым Source; еда вызвала реальные события лечения. Тестовый
TNT сохранил положение на полу в двух последовательных измерениях.

Изменения следующей сборки (подготовлены без запуска игр по просьбе пользователя):
- Жемчуг учитывает попадания в карту Source; хорус ищет место на её полу.
  Место телепорта проверяется лучами по габаритам персонажа; TraceHull
  в этой версии VScript отсутствует.
- ПКМ поддерживает удержание Source Use. ЛКМ передаёт Source Attack
  только для переносимых предметов событий (канистра, кола и подобные).
- Голем и обычные враждебные мобы преследуют Source-цели через реальные
  коллизии; скелеты сохраняют стрельбу, криперы — подготовку взрыва.
  Полноценный маршрут по navmesh Source и brain-driven мобы пока не реализованы.
- При загрузке и внешней камере/заморозке сцены композиция и ввод Minecraft
  отключаются. Курсор скрывается и его состояние восстанавливается по фокусу.
- Launcher принимает `-Map c2m1_highway` и другие имена карт Source.
  Экспериментальный захват глубины отключён после сообщений о просвечивании
  стен и исчезновении блоков при повороте камеры. Шейдер возвращён точно к
  проверенной версии 2550c2a. Используется Generic Depth; проверенная настройка
  CLEAR2 относится к c1m1_hotel. Другие карты требуют отдельной игровой проверки.

Последняя сборка Java/native и 35 Python-теста проходят. Новые телепорты,
удержания, преследование, скрытие курсора и изменения коллизий требуют игровой проверки.

Команды восстановления/подключения теперь ждут окончания загрузки Source,
чтобы не отправлять hijack-запрос в момент, когда движок его отклоняет.

Коррекция после новых сообщений пользователя (только код, без запуска игр):
- Мобы Minecraft видны и участвуют в бою, но не создают невидимые твёрдые
  Source-пропы: игрок может проходить сквозь них. Старые собственные
  номерные коллайдеры удаляются при следующем подключении скрипта.
- Двери и кнопки снова получают явный interact; принудительный IN_USE
  не применяется к ним, чтобы не вызвать повторный Toggle.
- Стены проверяются по ширине и трём высотам тела. Моб останавливается,
  если устарела проверка местности или он ушёл слишком далеко от неё.
  При частичном пересечении стены разрешается ближайший неглубокий выход;
  startsolid больше не превращается в четыре запирающие плоскости.
Эти изменения собраны и установлены, но ещё не проверены в игре: пользователь
явно попросил не открывать игры. Это не подтверждение полного исправления.


Новый пакет механик (2026-10-08, собран без открытия игр)

- Постройки и содержимое контейнеров сохраняются отдельно по имени карты
  Source в `saves/l4d2mc-guest/l4d2mc-maps`. Первая карта принимает существующие
  постройки. Автосохранение раз в 60 секунд, при переходе и остановке сервера.
  Ограничение архива — 20 000 блоков; повреждённый архив не применяется.
  Есть журнал перехода, checkpoint и flush vanilla-world перед удалением
  журнала; ранние чанки индексируются, контейнеры обновляются при выгрузке.
  Переход применяется порциями по 64 блока; ввод ждёт подтверждения готовности.
- Еда лечит постепенно: 4 HP Source на единицу питательности, по 2 HP каждые
  0.25 секунды. Очередь ограничена 100 HP. Золотое яблоко дополнительно даёт
  до 20 временных HP. Еда не поднимает павшего/висящего персонажа.
- Щит уменьшает урон от атак спереди, Tank его пробивает. Броня учитывает
  защиту и toughness, передаётся из реально надетых вещей, изнашивается.
  В скриптовом режиме используется цепочка AllowTakeDamage; в обычном coop
  fallback компенсирует только несмертельный урон после player_hurt и **не
  предотвращает падение от смертельного удара**. Fire/acid/fall не блокируются.
- Заражённые рядом с баррикадой повреждают её при прямой видимости. Скорость
  разрушения зависит от Minecraft hardness, Tank сильнее обычного заражённого.
  Неразрушаемые блоки сохраняются, разрушенные дают обычные Minecraft drops.
  Это давление по близости, полноценная анимация/выбор маршрута пока отсутствуют.
- Редкие смерти обычных заражённых могут оставлять хлеб, булыжник, железные
  самородки или стрелы. Инвентарь игрока сохраняет обычный Minecraft между главами.
- Урон стрел теперь зависит от скорости и реального baseDamage (включая Power),
  вместо постоянных 60 HP. Критическое попадание использует приближение ×1.25;
  специальные эффекты всех зачарований по Source не реализованы.
- Големам доступны follow/guard/attack. Guard защищает область радиусом
  12 блоков; follow возвращается к игроку после боя. Shift+ПКМ пустой рукой
  по голему включает follow. Маршруты строятся по Source navmesh, с проверкой высоты и свободного места для тела.

Команды в чате Minecraft (T, либо `/`):

| Команда | Действие |
|---|---|
| `/l4d2mc survival` | Ограниченные ресурсы, крафт и расход инструментов Minecraft; здоровье и ходьба остаются Source |
| `/l4d2mc creative` | Вернуть творческий инвентарь |
| `/l4d2mc golem follow` | Ближайший голем в пределах 12 блоков следует за игроком |
| `/l4d2mc golem guard` | Голем охраняет своё текущее место |
| `/l4d2mc golem attack` | Свободный выбор заражённых целей |
| `/l4d2mc save` | Сохранить постройки текущей карты |
| `/l4d2mc link` | Связать ближайший рычаг/нажимную плиту в пределах 6 блоков с дверью/кнопкой Source под прицелом |

Редстоун открывает/закрывает связанную дверь по сигналу, кнопку нажимает при
появлении сигнала. До 32 связей; привязки действуют в текущем подключении и
после перезапуска требуют повторения команды. Vanilla крафт, печи, сундуки,
броня, лук/арбалет и обычный редстоун работают внутри настоящего гостевого
Minecraft. Кровати ещё не являются checkpoint кампании Source; при новой карте и рестарте сцена очищается от мобов, предметов и блоков. Прежние постройки сохраняются в `saves/l4d2mc-guest/l4d2mc-maps/snapshots`; автоматического восстановления старой сцены нет.

Игровая проверка нового пакета не проведена по прямой просьбе пользователя.
Сборка Java и 40 Python-тестов проходят; это не подтверждает runtime callbacks,
редстоун, защиту, переходы, сохранение/восстановление или поведение мобов в игре.


## Обновление 9 октября: код установлен, проверка в игре ещё нужна

- `Launch-L4D2MC-2K.bat` запускает существующий мост и L4D2 в 2560×1440,
  оконном режиме без рамки. Это разрешение основного монитора. Minecraft
  профиль `L4D2MC-Fabric-26.3` предварительно запускается обычным Legacy Launcher.
- Esc открывает штатное меню L4D2 и закрывает гостевой экран; Minecraft pause
  больше не открывается. В меню L4D2 изображение гостя и его ввод отключены,
  курсором управляет VGUI. На возврате в игру реактивируется Source мышь.
- Щит защищает передний сектор 120°: обычные заражённые получают stumble,
  летящие Hunter/Jockey — stagger. Cooldown на врага 1.2 s. Tank не отражается.
  Захват Smoker спереди отражается щитом; удар мечом освобождает язык через
  stagger Smoker. Работу событий захвата необходимо проверить в игре.
- Огниво на реальном полу Source создаёт штатный DropFire, как огонь молотова:
  горение, заражённые и опасность для выживших обрабатываются движком. До шести
  очагов, повторный поджиг не чаще 0.5 s, собственные inferno убираются через
  12 s или при потере связи. В survival расходуется прочность огнива.
- Алмазный/незеритовый меч: обычный infected одним попаданием; специальные
  180/220 HP за удар, минимальный интервал 0.35 s. При базовом здоровье:
  Hunter/Smoker/Jockey — два удара, Charger — четыре/три, Tank —23/19.
  Здоровье зависит от режима и сложности; точные реакции ещё не проверены.
- Сердца Minecraft survival отображают Source HP (100 HP =20 MC HP);
  временное здоровье показано absorption. Incap/death ведёт Source, гостевой
  игрок сохраняется живым технически, вместо второго экрана смерти Minecraft.
- До восьми големов получают невидимую несолидную цель Source: заражённым
  выдаётся CommandABot attack, контактный урон уходит реальному мобу Minecraft.
  Големы не блокируют выживших. Прыжки — только через проверенный уступ до
  одного блока, при свободном месте над телом. Для глубокой коллизии с моделью
  предусмотрен поиск проверенной свободной позиции рядом.
- При захватах Hunter/Jockey/Smoker/Charger включается изображение Стива в
  третьем лице; полный перенос анимаций Source на скелет Minecraft не сделан.

## Броня, предметы и награды — 9 октября

Броня использует Minecraft armor/toughness с переводом5Source HP=1MC HP:
материалы с большей toughness лучше держат сильный удар. Прочность уменьшается
в единицах Minecraft, Unbreaking остаётся штатным; creative снаряжение не
изнашивает. Armor защищает физические удары/пули/взрывы. Fire Protection,
Blast Protection, Projectile Protection и Feather Falling вычисляются самим
Minecraft EnchantmentHelper по подходящему DamageSource; Protection действует
дополнительно. Resistance уменьшает остаток на20% за уровень, максимум80%;
Fire Resistance даёт иммунитет именно к огню, не кислоте Spitter. Щит остаётся
направленным и не заменяет броню против Tank/взрыва/падения.

Лечебные зелья и регенерация отправляют реальные Minecraft heal ticks в Source;
молоко снимает эффекты через обычный Minecraft, heartbeat обновляет защиту.
Золотое яблоко даёт еду/временное HP Source и свои Resistance/Fire Resistance,
если они есть у разновидности яблока. Strength усиливает полноценный удар
мечом; постоянный минимум180/220 не отменяет бонус положительного damage.
Броня и эффекты в обычном coop имеют fallback возврата несмертельного урона;
если Director pre-damage hook не вызывается, они не предотвращают incap/смерть
от первого сильного удара. Это существующее ограничение, не подтверждённая
полная защита; игровая проверка всё ещё не проводилась.

Награда создаётся по map_transition/finale_win, с проверкой alive и завершённого
выхода через changelevel volume, если карта его предоставляет. Просто открыть
дверь, сменить карту консолью или перезапустить уровень награды не даёт.
Один receipt на Source map+epoch сохраняется вместе с inventory/XP/repair
в player.dat частного мира. Перед ack выполняется save и чтение фактического
player.dat: swallowed Minecraft IO errors не удаляют Source outbox.
Полный инвентарь сохраняет остаток в reserve того же player.dat.

| Награда | Обычная глава |
|---|---|
| Еда | 4 хлеба |
| Стройматериалы | 32 булыжника |
| Стрелы | 16; Hard24; Expert32 |
| Железо | 3 слитка; Hard4; Expert5 |
| Каждая вторая глава | 1 золотое яблоко |
| Каждая третья глава | 1 алмаз |
| Опыт и ремонт | 10 XP; ремонт экипированных вещей на10% max durability |
| Успешный финал | Вместо периодических бонусов: 2 алмаза, 2 золотых яблока, 30XP |

`/l4d2mc supplies` переносит доступный запас в свободные слоты и показывает
оставшиеся предметы. Новые типы наград не создаются этой командой.
До256 receipt/player, до10000 единиц каждого предмета в запасе; при лимите
Source не получает ack и сохраняет запись для восстановления/расширения лимита.

Конфликт размеров: второй launcher/bridge отклоняется, гостю принадлежит один
WebSocket controller; поздние сообщения/close старого владельца защищены

не найден: обнаруженный конфликт устранён в коде, полная причина падения ещё
не подтверждена запуском.

## Предметы, поверхности, щит и HUD — 09.10.2026

Подбор предметов действует на всех картах, не только в сейвзонах.

|---|---|
| Аптечка | Золотое яблоко |
| Таблетки | 3 печенья |
| Адреналин | Зелье скорости; эффект передаётся в движение Source |
| Pistol / Magnum | Деревянный / каменный меч |
| SMG / помповый дробовик | Железный меч |
| Автомат / автоматический дробовик / melee | Алмазный меч |

Source сохраняет pickup в отдельную outbox до удаления native предмета.
Minecraft сохраняет receipt/reserve вместе с inventory в player.dat; ack
отправляется после чтения файла. Остаток при полном инвентаре сохраняется в
reserve (/l4d2mc supplies). Outbox переживает смену карты и reconnect.
Map spawns, предметы ботов и quest carry items сохраняются. Скрытые sidearm и
native melee оставлены для Source fallback и сброса. ПКМ сначала сбрасывает
carry, даже при прицеле на MC-блок/моба; native IN_USE подавляется до отпускания
ПКМ, чтобы сразу не подобрать его обратно. Следующий ПКМ открывает дверь.

Меч поражает до 8 противников в секторе 120 градусов перед игроком, учитывает
стены и союзников. Алмазный/незеритовый убивает common одним ударом; базовый
урон specials 180/220 плюс Minecraft damage bonus. Щит имеет 6 единиц запаса:
common расходует 1, special 2. Затем 5 секунд cooldown с индикатором Minecraft;
защита прекращается до восстановления. Один контакт с тем же врагом за 1.2s
не тратит запас повторно. Charger включён в проверку приближающихся specials.
Оговорка о nonlethal refund в обычном coop без pre-damage hook остаётся.

Исправлены нормали retail TraceLine (пол/огниво/низкие уступы), ошибочный
однопараметрический IsBlocked: [retail binding](https://vscript.l4d2node.org/c/TerrorNavArea).
Координата UseItemOnPacket ограничена выбранной AIR-клеткой; physical hit
сохраняется для прицеливания/огнива. Для пола берётся ближайшая высота сетки:
на наклоне до половины блока может выступать/погружаться, поскольку кубы
сохраняют общую сетку. Это устраняет full-block hover и отказ server packet.
Позиция Стива читается из клиентского кадра вместе с камерой без экстраполяции
server feet вперёд. VClientEntityList003 подтверждён в установленном client.dll;
методы проверены по L4D2 SDK. Guest fire/lava имеет leased DOT Source 2HP/0.5s;
native entityflame не дублируется. Вода/Fire Resistance и смена карты гасят таймер.
Screen/body flame синхронизированы с текущим состоянием горения.

HUD собирается `python tools/build_hud.py` из установленной копии игры,
не скачивает game assets: оружие справа скрыто, панель команды идёт снизу вверх
слева и уменьшена до 78%. Собранные game resources остаются в ignored dist.
Launcher включает собственный HUD для mashup и восстанавливает addon flags.
`passthrough/update.py` устанавливает только собственные готовые компоненты
без запуска игр; launcher вызывает его перед запуском, когда DLL свободна.

VScript syntax, Squirrel-моки floor/nav, shield capacity/cooldown и sword cone
(2 commons, союзник, цель сзади и за стеной), PowerShell syntax. Семь компонентов
установлены и проверены SHA-256. Игры не запускались и не закрывались; новые
визуальные/Source API пути пока не подтверждены в настоящей игровой сессии.
